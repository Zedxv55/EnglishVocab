==========================================
📚 คลังคำศัพท์ภาษาอังกฤษ (English Vocabulary)
==========================================

ไฟล์เริ่มต้น: เปิด index.html ด้วยเบราว์เซอร์ (ดับเบิลคลิก)
           หรือลากไฟล์ไปวางใน Chrome/Edge

----------------------------------------------------------
✔ เนื้อหา
----------------------------------------------------------
• คำศัพท์ 5,000 คำ ที่พบบ่อยที่สุดในภาษาอังกฤษ (เรียงตามความถี่)
• ทุกคำมี: คำศัพท์, คำอ่าน IPA, คำอ่านไทย (โดยประมาณ),
  หมวดคำ (noun/verb/adj/adv/...), คำแปลภาษาไทย
• ทำงานได้โดยไม่ต้องเชื่อมอินเทอร์เน็ต (ยกเว้นปุ่ม "แปลเป็นไทย"
  และ "ฟังเสียง" ในบางเครื่องที่ไม่มีเสียงอังกฤษติดตั้ง)

✔ ฟีเจอร์
----------------------------------------------------------
1. คำศัพท์      - ค้นหา (อังกฤษ/คำอ่าน/คำแปลไทย)
               - กรองหมวดคำ, ตัวอักษร A-Z, ความยาวคำ
               - เรียง A-Z / ตามความถี่ / สุ่ม
               - กดดาว ⭐ เพื่อบันทึกคำ (จำไว้ในเครื่อง)
               - กด 🔊 เพื่อฟังเสียงออกเสียง
2. การ์ดจำศัพท์ - กดการ์ดเพื่อพลิกดูคำแปล, สับไพ่, โหมดสุ่ม
3. แต่งประโยค   - เลือกแบบประโยค 16 แบบ, กดช่อง [ ] เพื่อเลือกคำ
               - กรอกคำเองได้, สุ่มเติม, ฟังเสียง, แปลไทย, คัดลอก
4. แปลภาษา      - อังกฤษ ⇄ ไทย (ต้องเชื่อมอินเทอร์เน็ต)

----------------------------------------------------------
ไฟล์และโฟลเดอร์
----------------------------------------------------------
index.html, app.js, style.css   = ตัวเว็บ
data/words.js                   = ข้อมูลคำศัพท์ทั้งหมด
data/translations.jsonl         = คำแปลดิบ (สำหรับสร้างใหม่)
data/cmudict.dict, wordlist.txt = แหล่งข้อมูลคำอ่านและรายการคำ
scripts/translate.py            = สคริปต์แปลคำศัพท์ (ต้องการอินเทอร์เน็ต)
scripts/build_words.py          = สคริปต์ประกอบข้อมูลเป็น words.js

สร้างข้อมูลใหม่:  cd EnglishVocab
    python scripts/translate.py 5000
    python scripts/build_words.py

----------------------------------------------------------
หมายเหตุ
- คำอ่านภาษาไทยเป็นแบบ "โดยประมาณ" (อัตโนมัติจากเสียง IPA)
- หมวดคำได้จากกฎอัตโนมัติ อาจมีคำที่จัดหมวดไม่ตรงบ้าง
