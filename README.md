# EnglishVocab SRS

**EnglishVocab SRS** คือเว็บแอปท่องศัพท์ภาษาอังกฤษสำหรับผู้เรียนไทย ที่ปรับปรุงจากเวอร์ชันเดิมให้เป็น **React + TypeScript + Vite** และเพิ่มระบบทบทวนแบบ Spaced Repetition

> จำได้ดีขึ้นทีละคำ — ทบทวนคำศัพท์ตามระยะเวลาที่เหมาะกับระดับความจำของผู้เรียน

## ความสามารถหลัก

| ความสามารถ | รายละเอียด |
|---|---|
| คลังคำศัพท์ | โหลดคำศัพท์เดิมกว่า 5,000 คำ พร้อม IPA, คำอ่านไทย, ชนิดของคำ และคำแปลไทย |
| ระบบ SRS | ใช้อัลกอริทึม SM-2 ที่ปรับ interval, ease factor และวันครบกำหนดทบทวนตามคำตอบของผู้ใช้ |
| บัตรคำ | แสดงคำศัพท์ก่อน ให้ผู้เรียนนึกคำตอบ แล้วเลือกระดับ **จำไม่ได้ / ยาก / ดี / ง่าย** |
| คีย์บอร์ด | กด `Space` เพื่อดูเฉลย และกด `1`–`4` เพื่อบันทึกระดับการจำได้ |
| คลังค้นหา | ค้นหาด้วยคำศัพท์ คำอ่าน หรือคำแปลไทย พร้อมแถบตัวอักษร A–Z สำหรับกระโดดไปยังคำที่เริ่มต้นด้วยตัวอักษรที่ต้องการ และกรองตามชนิดของคำ และเพิ่มคำเข้าตารางทบทวนเองได้ |
| ความเป็นส่วนตัว | ความคืบหน้าและคำที่บันทึกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เท่านั้น |

## AI ทูเตอร์ — AI ช่วยวางแผนการเรียน

เมื่อผู้ใช้ต้องการใช้หรือเรียนสามารถให้ AI ช่วยวางแผนการเรียนได้ทันที ผ่านคอมโพเนนต์ `AiTutor` ที่เรียก Mistral API ผ่าน proxy ของเซิร์ฟเวอร์ (`POST /api/mistral/chat`) ดังนี้ API key จึงไม่ถูกส่งออกจากเครื่องผู้ใช้

| ความสามารถ | รายละเอียด |
|---|---|
| จัดแผนการเรียน | AI สร้างแผนเรียนส่วนตัว 4 สัปดาห์ พร้อมตารางทบทวนรายวัน เทคนิคการจำ และประโยคตัวอย่าง โดยอิงจากคำที่ผู้เรียนเลือก ระดับ (พื้นฐาน/กลาง/ขั้นสูง) เวลาเรียนต่อวัน และเป้าหมาย (เช่น สอบ TOEIC) |
| ถาม–ตอบ AI | ถามคำถามเกี่ยวกับคำศัพท์และหลักภาษาได้ตลอด 24 ชั่วโมง AI จะอธิบายเป็นภาษาไทยพร้อมตัวอย่างสั้น |
| การตั้งค่า | กดปุ่มรูปประแจในแผง AI เพื่อใส่ Mistral API key ของคุณ (เก็บเฉพาะในเครื่องของคุณผ่าน `localStorage`) |

## Beginner Path — เริ่มจากศูนย์

หน้า Today มีบทเรียนสั้นวันละประมาณ 10 นาทีสำหรับผู้ที่ยังไม่เก่งภาษาอังกฤษ โดยแบ่งเป็นสามขั้น ได้แก่ ฟังและพูดตามคำศัพท์ด้วยเสียงภาษาอังกฤษของเบราว์เซอร์, อ่านคำแปลและเริ่มบัตรคำ SRS, และทำแบบทดสอบความเข้าใจทันที ระบบจะจำสถานะว่าทำบทเรียนของวันนั้นแล้วไว้ในเบราว์เซอร์ เพื่อช่วยสร้างนิสัยโดยไม่กดดันผู้เรียน

ฟีเจอร์นี้ออกแบบให้ผู้ใช้เริ่มได้ทันทีโดยไม่ต้องรู้ศัพท์มาก่อน และเชื่อมต่อกับระบบทบทวนเดิม เมื่อทำต่อเนื่องจะได้ทั้งการเห็นคำศัพท์ การออกเสียง การนึกความหมาย และการตรวจความเข้าใจในหนึ่งรอบการเรียนรู้

| ส่วน | สิ่งที่ผู้เรียนได้รับ |
|---|---|
| ฟังและพูดตาม | ปุ่มเสียงภาษาอังกฤษสำหรับคำศัพท์ 5 คำแรกของบทเรียน |
| จำจากบริบท | ปุ่มเริ่มบัตรคำเพื่อใช้ระบบ Spaced Repetition เดิม |
| เช็กความเข้าใจ | แบบทดสอบเลือกคำแปล พร้อมเฉลยและคำแนะนำทันที |

## กติกาการทบทวน

| คำตอบ | กำหนดการรอบถัดไป |
|---|---|
| จำไม่ได้ | 10 นาที และลด ease factor |
| ยาก | อย่างน้อย 1 วัน พร้อมลด ease factor เล็กน้อย |
| ดี | 1 วัน → 3 วัน → เติบโตตาม ease factor |
| ง่าย | เริ่มที่ 4 วัน แล้วเว้นช่วงกว้างกว่าระดับ “ดี” |

## เริ่มต้นใช้งาน

ต้องใช้ Node.js 22 ขึ้นไป และ pnpm

```bash
pnpm install
pnpm dev
```

เปิดที่ `http://localhost:3000`

## ตรวจสอบก่อน build

```bash
pnpm check
pnpm build
```

## โครงสร้างสำคัญ

```text
client/src/
├── hooks/useVocabulary.ts  # โหลดคลังคำศัพท์เดิม
├── lib/srs.ts              # อัลกอริทึม Spaced Repetition
├── pages/Home.tsx          # Dashboard, flashcard, library และ progress
└── index.css               # ระบบภาพ Study Ledger
```
