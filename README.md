# 📚 EnglishVocab — คลังคำศัพท์ภาษาอังกฤษ

เว็บคลังคำศัพท์ภาษาอังกฤษ 5,000 คำ (พบบ่อยที่สุด 10,000 คำแรกของภาษา) ใช้งานง่าย เปิดได้ทันทีจากเครื่อง ไม่ต้องติดตั้งอะไร

## ✨ ฟีเจอร์

- **📖 คำศัพท์ 5,000 คำ** — ค้นหา, กรองหมวดคำ (noun/verb/adj/adv/...), กรองตัวอักษร A–Z, กรองความยาว
- **🔤 คำอ่าน** — IPA (96.5% ของคำ) + คำอ่านแบบอักษรไทย (สร้างอัตโนมัติจากเสียง) + 🔊 ฟังเสียงออกเสียง
- **🇹🇭 คำแปลไทย** — ครบ 100% ของ 5,000 คำ
- **🃏 การ์ดจำศัพท์** — พลิกการ์ด, รู้แล้ว/ยังจำไม่ได้, สับไพ่, สุ่มกอง
- **✍️ แต่งประโยค** — แม่แบบประโยค 16 แบบ, เลือกคำจากคลัง, สุ่มเติมอัตโนมัติ (จัดการพหูพจน์), แปลทั้งประโยค
- **🌐 ตัวแปลภาษา** — อังกฤษ ⇄ ไทย (ใช้ Google Translate endpoint สาธารณะ)
- ⭐ บันทึกคำที่ชอบ

## 🚀 วิธีเปิดใช้

เปิด `index.html` ในโฟลเดอร์นี้ด้วยเบราว์เซอร์ (Chrome/Edge/Firefox) — ใช้ได้ทันที

> หมายเหตุ: ข้อมูลคำศัพท์ฝังอยู่ใน `data/words.js` (เปิดผ่าน `file://` ได้ไม่ต้องรันเซิร์ฟเวอร์)
> ปุ่มแปลภาษาและเสียงอ่านต้องต่ออินเทอร์เน็ต ฟีเจอร์อื่นใช้ได้แบบออฟไลน์

## 🏗️ วิธีสร้างข้อมูลใหม่ (เพิ่มจำนวนคำ)

```bash
# 1. แปลคำศัพท์ (N = จำนวนคำ เช่น 10000)
python scripts/translate.py 10000

# 2. ประกอบข้อมูล คำอ่าน IPA + คำอ่านไทย + หมวดคำ + คำแปล → data/words.js
python scripts/build_words.py
```

### แหล่งที่มาของข้อมูล
- รายการคำ: [google-10000-english](https://github.com/first20hours/google-10000-english) (เรียงตามความถี่)
- คำอ่าน IPA: CMU Pronouncing Dictionary
- คำแปลไทย: Google Translate (endpoint สาธารณะ)

## 📂 โครงสร้าง

```
EnglishVocab/
├── index.html          # หน้าเว็บหลัก (แท็บ: คำศัพท์/การ์ด/แต่งประโยค/แปล)
├── style.css           # สไตล์
├── app.js              # ระบบทั้งหมด (ค้นหา/กรอง/การ์ด/แต่งประโยค/แปล)
├── data/
│   ├── words.js        # ข้อมูล 5,000 คำ {w, ipa, th_ipa, pos, th}
│   ├── translations.jsonl   # checkpoint คำแปล
│   ├── wordlist.txt    # รายการคำต้นทาง 10,000 คำ
│   └── cmudict.dict    # CMU Pronouncing Dictionary
└── scripts/
    ├── translate.py    # สคริปต์แปล (resume ได้)
    └── build_words.py  # ประกอบข้อมูล → words.js
```

## ⚠️ หมายเหตุ

- คำอ่านไทยเป็นแบบ**โดยประมาณ** (แปลงจากเสียง IPA อัตโนมัติ) — คำหลักออกเสียงถูก เช่น แอปเพิล, เทบเบิล, มอร์นอิง
- ใช้ได้ฟรี ไม่มีค่าใช้จ่าย ไม่ต้องใช้ API key
