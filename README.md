# EnglishVocab SRS

**EnglishVocab SRS** คือเว็บแอปท่องศัพท์ภาษาอังกฤษสำหรับผู้เรียนไทย ที่ปรับปรุงจากเวอร์ชันเดิมให้เป็น **React + TypeScript + Vite** และเพิ่มระบบทบทวนแบบ Spaced Repetition

> จำได้ดีขึ้นทีละคำ — ทบทวนคำศัพท์ตามระยะเวลาที่เหมาะกับระดับความจำของผู้เรียน

## ความสามารถหลัก

| ความสามารถ | รายละเอียด |
|---|---|
| คลังคำศัพท์ | โหลดคำศัพท์เดิมกว่า 5,000 คำ พร้อม IPA, คำอ่านไทย, ชนิดของคำ และคำแปลไทย |
| ระบบ SRS | ใช้อัลกอริทึม SM-2 ที่ปรับ interval, ease factor และวันครบกำหนดทบทวนตามคำตอบของผู้ใช้ |
| บัตรคำ | แสดงคำศัพท์ก่อน ให้ผู้เรียนนึกคำตอบ แล้วเลือกระดับ **จำไม่ได้ / ยาก / ดี / ง่าย** |
| คีย์บอร์ด | กด `Space` เพื่อดูเฉลย และกด `1`–`4` เพื่อบันทึกระดับการจำได้ |
| คลังค้นหา | ค้นหาด้วยคำศัพท์ คำอ่าน หรือคำแปลไทย พร้อมแถบตัวอักษร A–Z สำหรับกระโดดไปยังคำที่เริ่มต้นด้วยตัวอักษรที่ต้องการ และกรองตามชนิดของคำ และเพิ่มคำเข้าตารางทบทวนเองได้ |
| ความเป็นส่วนตัว | ความคืบหน้าและคำที่บันทึกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เท่านั้น |

## AI ทูเตอร์ — AI ช่วยวางแผนการเรียน

เมื่อผู้ใช้ต้องการใช้หรือเรียนสามารถให้ AI ช่วยวางแผนการเรียนได้ทันที ผ่านคอมโพเนนต์ `AiTutor` ที่เรียก Mistral API ผ่าน proxy ของเซิร์ฟเวอร์ (`POST /api/mistral/chat`) ดังนี้ API key จึงไม่ถูกส่งออกจากเครื่องผู้ใช้

| ความสามารถ | รายละเอียด |
|---|---|
| จัดแผนการเรียน | AI สร้างแผนเรียนส่วนตัว 4 สัปดาห์ พร้อมตารางทบทวนรายวัน เทคนิคการจำ และประโยคตัวอย่าง โดยอิงจากคำที่ผู้เรียนเลือก ระดับ (พื้นฐาน/กลาง/ขั้นสูง) เวลาเรียนต่อวัน และเป้าหมาย (เช่น สอบ TOEIC) |
| ถาม–ตอบ AI | ถามคำถามเกี่ยวกับคำศัพท์และหลักภาษาได้ตลอด 24 ชั่วโมง AI จะอธิบายเป็นภาษาไทยพร้อมตัวอย่างสั้น |
| การตั้งค่า | กดปุ่มรูปประแจในแผง AI เพื่อใส่ Mistral API key ของคุณ (เก็บเฉพาะในเครื่องของคุณผ่าน `localStorage`) |

## AI Learning Hub — ผู้ช่วยค้นหา อธิบาย แปล และฝึกแบบเฉพาะบุคคล

**AI Learning Hub** คือจุดเดียวสำหรับผู้เริ่มต้นที่ไม่รู้ว่าจะถามหรือเรียนต่ออย่างไร ผู้ใช้พิมพ์ภาษาไทยหรือภาษาอังกฤษได้ แล้วเลือกให้ AI ช่วยค้นหาคำ อธิบายคำหรือไวยากรณ์ แปลตามบริบท สร้างชุดคำศัพท์ หรือสร้างแบบฝึกหัดแบบเลือกตอบได้ทันที ระบบส่งคำขอผ่าน `POST /api/mistral/chat` และแปลงคำตอบเป็นโครงสร้างบทเรียนที่แสดงชื่อเรื่อง สรุป คำศัพท์ ตัวอย่างประโยค และแบบฝึกหัดในหน้าเดียว

| โหมด | ใช้เมื่อ | ผลลัพธ์ที่ได้ |
|---|---|---|
| ช่วยฉันเลือก | ยังไม่แน่ใจว่าควรเริ่มจากอะไร | AI เลือกรูปแบบการช่วยเหลือที่เหมาะกับคำถาม |
| ค้นหาคำ | ต้องการหาคำศัพท์จากความหมายหรือบริบท | คำที่ใกล้เคียง ความแตกต่าง และตัวอย่าง |
| อธิบายคำ/แกรมมาร์ | ไม่เข้าใจคำหรือหลักภาษา | คำอธิบายภาษาไทยแบบง่าย พร้อมตัวอย่างอังกฤษ |
| แปลตามบริบท | ต้องการแปลประโยคให้ใช้ได้จริง | ตัวเลือกภาษาอังกฤษหลายระดับพร้อมบริบท |
| สร้างชุดคำ | ต้องการคำศัพท์ตามหัวข้อหรือเป้าหมาย | ชุดคำ 8–12 คำ พร้อมชนิดของคำและประโยค |
| สร้างแบบฝึกหัด | ต้องการฝึกทันทีหลังเรียน | แบบฝึกหัด 4–6 ข้อพร้อมเฉลยและคำอธิบาย |

คำตอบจาก AI ถูกตรวจและแปลงจาก JSON ทั้งกรณีที่ Mistral ส่ง JSON ตรง ๆ หรือครอบด้วย code fence จึงยังแสดงคำตอบแบบข้อความได้หากโครงสร้างบางส่วนไม่สมบูรณ์ นอกจากนี้ผู้เรียนสามารถกดฟังคำศัพท์ เพิ่มคำที่มีอยู่ในคลังเข้าระบบทบทวน และเลือกทำข้อฝึกหัดในผลลัพธ์ได้ทันที คำถามล่าสุดจะใช้ร่วมกับระดับผู้เรียนและคำศัพท์ที่กำลังทบทวนเพื่อให้คำแนะนำเหมาะกับแต่ละคนมากขึ้น

### การตั้งค่า AI Learning Hub

1. เปิดแอปแล้วกดปุ่ม **ตั้งค่า AI** บริเวณด้านล่างของหน้า
2. วาง Mistral API key ของผู้ใช้เอง แล้วบันทึกไว้ในเบราว์เซอร์เครื่องนั้น
3. เปิดส่วน **AI Learning Hub** พิมพ์คำถาม และกด **ให้ AI ช่วย** หรือกด `Ctrl/Cmd + Enter`
4. หากไม่ต้องการใช้โหมดอัตโนมัติ ให้เลือกโหมดที่ตรงกับเป้าหมายก่อนส่งคำถาม

คีย์ที่ใช้ในการพัฒนา **ไม่ควร commit ลง Git** และในเวอร์ชันใช้งานจริงควรเก็บคีย์ไว้ในตัวแปรสภาพแวดล้อมของเซิร์ฟเวอร์ เช่น `MISTRAL_API_KEY` ส่วนคีย์ที่ผู้ใช้กรอกเองจะถูกเก็บเฉพาะใน `localStorage` ของเบราว์เซอร์นั้นตามการออกแบบของแอป

## Placement Test — วัดระดับและแผนเรียน 7 วันอัตโนมัติ

ในหน้า Today ผู้ใช้ที่ไม่แน่ใจว่าจะเริ่มจากจุดไหนสามารถกด **เริ่มวัดระดับ** เพื่อตอบแบบทดสอบ 10 ข้อที่สร้างโดย AI ใหม่ทุกครั้งที่ทำ คำถามเริ่มจากง่ายมากแล้วค่อย ๆ ยากขึ้น ระบบจะบอกคะแนนและระดับที่แนะนำ (ระดับเริ่มต้นจากศูนย์ / ระดับเริ่มต้น / ระดับกลาง) แล้วสร้าง **แผนเรียน 7 วัน** แบบตารางอัตโนมัติตามระดับและคำศัพท์ที่ผู้เรียนเลือก แผนถูกบันทึกในเบราว์เซอร์เพื่อให้กลับมาดูได้ทุกวัน

| ส่วน | สิ่งที่ผู้เรียนได้รับ |
|---|---|
| แบบทดสอบ AI | 10 ข้อแบบเลือกตอบ สร้างใหม่ทุกครั้งที่ทำ พร้อมคำอธิบายภาษาไทยทีละข้อ |
| ผลการวัดระดับ | คะแนนและระดับที่แนะนำ พร้อมคำแนะนำเป็นภาษาไทย |
| แผน 7 วัน | ตารางรายวันแยกคำศัพท์ กิจกรรม และเวลาเรียน พร้อมกฎสามข้อของสัปดาห์แรก |

## สถานการณ์จริง — Scenario Lab

คอมโพเนนต์ `ScenarioLab` มีสถานการณ์ฝึกภาษาอังกฤษแปดแบบ ได้แก่ สั่งอาหารและกาแฟ, เช็คอินโรงแรม, เดินทางและถามทาง, ทักทายเพื่อนใหม่, ซื้อของและต่อรองราคา, ที่ทำงานและการสัมภาษณ์เบื้องต้น, พบหมอและร้านยา และโทรศัพท์และแชทเบื้องต้น เมื่อเลือกสถานการณ์ AI จะสร้างบทสนทนาสั้นภาษาอังกฤษพร้อมคำแปลภาษาไทย, ตารางคำสำคัญห้าคำที่ควรจำ และท่าฝึกพูดสามท่า ผู้เรียนสามารถฟังเสียงคำศัพท์สำคัญและกดสร้างบทเรียนสถานการณ์ใหม่ได้ไม่จำกัด

## ฝึกแต่งประโยค — Sentence Gym

ใต้ส่วน Scenario Lab มีช่องพิมพ์ประโยคภาษาอังกฤษฟรี ผู้เรียนพิมพ์ประโยคที่อยากพูดได้เองโดยไม่ต้องกลัวผิด แล้ว AI จะให้คำตัดสิน (ผ่านเลย / ใกล้แล้ว / ลองอีกที) พร้อมประโยคที่ปรับแล้ว, คำอธิบายสาเหตุแบบเข้าใจง่าย และประโยคทางเลือกอื่น การฝึกเขียนเองคือขั้นตอนที่เปลี่ยนการจำคำให้เป็นการใช้คำเป็น

## สถิติรายสัปดาห์

หน้าความคืบหน้า (Insights) แสดงกราฟการทบทวนเจ็ดวันล่าสุดโดยอิงจากบันทึกการทบทวนรายวันที่ระบบเก็บลงใน `localStorage` ทุกครั้งที่ทบทวนบัตรคำ ผู้เรียนจึงเห็นจังหวะการเรียนของตัวเองและเปรียบเทียบความสม่ำเสมอระหว่างสัปดาห์ได้

## Beginner Path — เริ่มจากศูนย์

หน้า Today มีบทเรียนสั้นวันละประมาณ 10 นาทีสำหรับผู้ที่ยังไม่เก่งภาษาอังกฤษ โดยแบ่งเป็นสามขั้น ได้แก่ ฟังและพูดตามคำศัพท์ด้วยเสียงภาษาอังกฤษของเบราว์เซอร์, อ่านคำแปลและเริ่มบัตรคำ SRS, และทำแบบทดสอบความเข้าใจทันที ระบบจะจำสถานะว่าทำบทเรียนของวันนั้นแล้วไว้ในเบราว์เซอร์ เพื่อช่วยสร้างนิสัยโดยไม่กดดันผู้เรียน

ฟีเจอร์นี้ออกแบบให้ผู้ใช้เริ่มได้ทันทีโดยไม่ต้องรู้ศัพท์มาก่อน และเชื่อมต่อกับระบบทบทวนเดิม เมื่อทำต่อเนื่องจะได้ทั้งการเห็นคำศัพท์ การออกเสียง การนึกความหมาย และการตรวจความเข้าใจในหนึ่งรอบการเรียนรู้

| ส่วน | สิ่งที่ผู้เรียนได้รับ |
|---|---|
| ฟังและพูดตาม | ปุ่มเสียงภาษาอังกฤษสำหรับคำศัพท์ 5 คำแรกของบทเรียน |
| จำจากบริบท | ปุ่มเริ่มบัตรคำเพื่อใช้ระบบ Spaced Repetition เดิม |
| เช็กความเข้าใจ | แบบทดสอบเลือกคำแปล พร้อมเฉลยและคำแนะนำทันที |

## แบบฝึกหัดการฟัง — Listening Drill

คอมโพเนนต์ `ListeningDrill` ให้ผู้เรียนฟังเสียงคำศัพท์จากเทคโนโลยี Text-to-Speech ของเบราว์เซอร์ แล้วเลือกคำที่ได้ยินหรือพิมพ์ตามที่ได้ยิน โดยกดฟังซ้ำได้ไม่จำกัดและสลับคำศัพท์ชุดใหม่ได้ การฝึกฟังซ้ำ ๆ ช่วยเชื่อมโยงเสียงกับตัวสะกดและความหมาย

## โหมดเกมทบทวน — Review Games

คอมโพเนนต์ `ReviewGames` มีสามโหมด ได้แก่ **จับคู่** (จับคู่คำภาษาอังกฤษกับคำแปลไทยแข่งเวลา), **พิมพ์แข่งเวลา** (พิมพ์ความหมายให้ครบภายในเวลาที่กำหนด) และ **เติมคำ** (เติมคำที่ขาดในประโยค) ทุกคำตอบที่ถูกต้องจะถูกนับเป็นการทบทวนและบันทึกความคืบหน้าเข้าระบบ SRS อัตโนมัติ

## ฝึกสนทนากับ AI — Chat Practice

คอมโพเนนต์ `ChatPractice` ให้ผู้เรียนเลือกสถานการณ์ เช่น สั่งอาหาร เช็คอินโรงแรม สอบสัมภาษณ์งาน แล้วสนทนาบทบาทสมมติกับ AI โดย AI ตอบเป็นภาษาอังกฤษง่าย ๆ พร้อมคำแปลภาษาไทยในวงเล็บ ผู้เรียนสามารถกดฟังเสียง AI ด้วยปุ่มลำโพง และ AI จะแก้ประโยคของผู้เรียนหากพิมพ์ผิด ทำให้ผู้เรียนได้ฝึกใช้ภาษาอังกฤษจริง ไม่ใช่แค่ท่องคำศัพท์

## Streak และเป้าหมายรายวัน

ระบบนับจำนวนวันเรียนต่อเนื่อง (streak) และแสดงเป้าหมายรายวัน (จำนวนรอบทบทวนต่อวัน ที่ผู้เรียนตั้งได้เอง) ในหน้า Today ทุกครั้งที่มีการทบทวนหรือเล่นเกม ระบบจะบันทึกสถิติรายวันเพื่อให้ streak เพิ่มขึ้นเมื่อเรียนครบเป้าหมาย ช่วยสร้างนิสัยการเรียนสม่ำเสมอ
